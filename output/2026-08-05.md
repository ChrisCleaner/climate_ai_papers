# FESOM2-JAX v1.0 Research Summary

**Main Contribution:**
A fully differentiable Python reimplementation of FESOM2 (a global ocean-sea-ice model) in JAX that maintains scientific fidelity while enabling gradient-based optimization and hybrid physics-ML approaches. The model scales from laptops to 256 GPUs while preserving the unstructured-mesh finite-volume formulation of the original Fortran code.

**Method:**
- JAX-based automatic differentiation framework enabling end-to-end gradient computation through full time loops
- Kernel-by-kernel verification against original Fortran FESOM2 using finite differences
- Reverse-mode automatic differentiation to compute parameter sensitivities at every mesh vertex
- Unstructured mesh (up to 7.4M surface vertices) with cell-vertex finite-volume discretization

**Data:**
1958–2019 hindcast simulation at ~1° equivalent resolution using identical physics and forcing as original FESOM2; validation against observational differences.

**Climate Relevance:**
Enables gradient-based calibration of ocean-sea-ice models and integration of machine learning components into CMIP-class climate models, improving parameter optimization and uncertainty quantification for global ocean dynamics and sea-ice evolution.

**Implications:**
Accelerates model development cycles, reduces computational barriers for climate modeling research, facilitates inverse modeling and data assimilation, and provides a template for differentiable implementations of other complex Earth system models.

**Limitations:**
Communication bandwidth (not arithmetic) becomes the limiting factor at scale; transferability of ML-enhanced components back to production Fortran code requires validation.

**TL;DR:**
First differentiable CMIP-complexity ocean-sea-ice model on unstructured meshes, enabling gradient-based optimization and physics-ML hybrid approaches while maintaining scientific accuracy.

### [Memory compression and physical state augmentation favor different AMOC prediction tasks](https://arxiv.org/abs/2607.28468v1)

**Categories:** physics.ao-ph, math.DS, stat.AP

# Research Summary: Memory Compression vs. Physical State for AMOC Prediction

**Main Contribution:**
Demonstrates that memory-based (scalar compression) and physics-based (thermohaline structure) approaches optimize different prediction horizons for Atlantic Meridional Overturning Circulation forecasting. Shows that compact memory outperforms explicit physical state across recursive prediction tasks despite discarding structural information.

**Method:**
- Compared two neural network strategies: (1) direct input of salinity/temperature/density fields, (2) compressed scalar memory of observed indices
- Leave-one-family-out cross-validation across 8 CMIP6 model families using 30 branch-consistent trajectories
- Resolvent analysis to explain learned model stability properties
- Ablation studies isolating memory feedback contributions

**Data:**
CMIP6 multi-model ensemble (8 families); 20-year direct forecasts and recursive long-horizon predictions under SSP5-8.5 emissions scenario

**Climate Relevance:**
AMOC is a critical climate tipping point regulating heat transport and regional climate impacts. Current monitoring relies on reduced indices that lose thermohaline information; this work optimizes emulation strategies for operational forecasting.

**Implications:**
Memory-compressed models enable efficient, skillful AMOC predictions at decadal scales. Physical augmentation better captures near-term ocean state changes. Results inform design of hybrid prediction systems balancing computational efficiency with forecast skill.

**Limitations:**
Model-dependent performance (negative transfer in MIROC); forcing-dependent compression limits in NorESM suggest generalization challenges across emission scenarios.

**TL;DR:**
Compact memory outperforms physical state for long-horizon AMOC prediction, but physical augmentation excels at short-term ocean state forecasting.

# Research Summary: Network-Based Streamflow Alteration Mapping

**Main Contribution:**
Introduces the Streamflow Alteration Index (SAI), a network-based screening metric that maps downstream propagation of hydrologic alterations from dams and water infrastructure across river networks without requiring detailed operational data.

**Method:**
• Routes point-based alteration signals through a hydrologic routing network (OLRRP v2)
• Generates paired indices (SAI_I for confirmed sources, SAI_II for potential sources) on 0-100% scale
• Applies classification algorithm to categorize subbasins as natural, conditional, or altered
• Validates against independent reference datasets (RHBN gauges, WSC labels)

**Data:**
Ontario Lake and River Routing Product v2 (OLRRP v2); inventory of 643 alteration sources from provincial datasets; Reference Hydrometric Basin Network (RHBN) gauges; Water Survey of Canada (WSC) natural/regulated classifications.

**Climate Relevance:**
Supports climate adaptation planning by identifying how water infrastructure modifies streamflow regimes, critical for assessing ecosystem resilience and water availability under changing precipitation patterns.

**Implications:**
Enables rapid, objective screening for hydrologic modeling and aquatic ecosystem assessments at ungauged sites; provides scalable framework for national-to-global infrastructure impact mapping without intensive data requirements.

**Limitations:**
Validation limited to Ontario; classification accuracy lower for regulated gauges (74% conditional/natural vs. 86% for natural); does not incorporate dam operating rules or temporal dynamics of alteration.

**TL;DR:**
Network-propagated alteration index enables large-scale, data-efficient mapping of streamflow impacts from water infrastructure without detailed operational information.
