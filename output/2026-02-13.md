# Research Summary: Function-Space Decoupled Diffusion for CCS Modeling

**Main Contribution:**
Introduces Fun-DDPS, a generative framework combining function-space diffusion models with neural operator surrogates to solve ill-posed inverse problems in subsurface characterization with sparse observations. Achieves 11x error reduction in forward modeling and provides first rigorous validation of diffusion-based inverse solvers against ground-truth posteriors.

**Method:**
- Single-channel diffusion model learns prior distribution over geological parameters (geomodel)
- Local Neural Operator (LNO) surrogate provides physics-consistent guidance via cross-field conditioning
- Decoupled architecture separates parameter-space recovery from dynamics-field guidance
- Gradient-based data assimilation leverages differentiable surrogate for efficient inference

**Data:**
Synthetic Carbon Capture and Storage (CCS) modeling datasets with controlled observation sparsity (tested at 25% data availability).

**Climate Relevance:**
Directly supports CCS deployment—a critical climate mitigation technology requiring accurate subsurface characterization for safe CO₂ storage in geological formations. Addresses fundamental challenge of sparse monitoring data in subsurface applications.

**Implications:**
Enables reliable CCS site characterization with minimal observation networks, reducing deployment costs and accelerating large-scale carbon storage projects. Methodology generalizable to other subsurface inverse problems (geothermal, hydrocarbon).

**Limitations:**
Validation limited to synthetic datasets; real-world applicability requires testing on field data with actual measurement noise and geological complexity. Computational cost comparison with traditional inversion methods not explicitly discussed.

**TL;DR:**
Decoupled diffusion framework achieves 11x improved accuracy for sparse-data subsurface modeling, enabling practical CCS deployment with minimal monitoring infrastructure.
