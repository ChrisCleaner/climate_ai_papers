# FESOM2-JAX v1.0 Summary

**Main Contribution:**
A fully differentiable Python reimplementation of the FESOM2 ocean-sea-ice model in JAX that maintains scientific fidelity to the original Fortran code while enabling GPU acceleration and gradient-based optimization.

**Method:**
- JAX-based re-implementation preserving unstructured-mesh, cell-vertex finite-volume formulation
- End-to-end automatic differentiation via reverse-mode autodiff through full time loops
- Kernel-by-kernel verification against original Fortran model using finite differences
- Scalable from single CPU/GPU to 256 GPUs with identical physics

**Data:**
1958–2019 hindcast forcing; validation against observational temperature, salinity, heat content, and sea ice records.

**Climate Relevance:**
Enables gradient-based calibration and sensitivity analysis of a CMIP-class global ocean-sea-ice model, critical for understanding parameter uncertainty in climate projections and improving parameterizations of ocean dynamics and sea-ice processes.

**Implications:**
- Facilitates hybrid physics-machine-learning components for climate modeling
- Allows efficient parameter optimization and uncertainty quantification
- Reduces computational barriers for experimenting with new numerics and parameterizations
- Findings transferable back to operational Fortran model

**Limitations:**
Scalability limited by inter-GPU communication rather than computation; largest tested mesh (~7.4M vertices) scales to 128 GPUs.

**TL;DR:**
First CMIP-complexity ocean model on unstructured meshes with native differentiability, enabling gradient-based optimization and hybrid ML-physics approaches while maintaining accuracy parity with the original.

**TL;DR:**

# Research Summary: Network-Based Streamflow Alteration Mapping

**Main Contribution:**
Introduces the Streamflow Alteration Index (SAI), a network-based screening metric that maps how dams and water infrastructure alter streamflow across entire river networks. Enables spatially continuous assessment at both gauged and ungauged locations without requiring detailed operational data.

**Method:**
• Routes point-based alteration signals (from dams/reservoirs) downstream through hydrologic routing networks
• Generates paired indices: SAI_I (confirmed sources) and SAI_II (potential sources), both scaled 0-100%
• Classifies subbasins as natural, conditional, or altered based on cumulative downstream influence
• Validates against independent reference datasets (RHBN gauges, WSC labels)

**Data:**
Ontario Lake and River Routing Product v2 (OLRRP v2); inventory of 643 alteration sources from provincial datasets; Reference Hydrometric Basin Network (RHBN) gauges; Water Survey of Canada (WSC) natural/regulated classifications.

**Climate Relevance:**
Streamflow alteration affects aquatic ecosystem health, water availability under climate change, and hydrologic model accuracy—critical for assessing climate impacts on freshwater systems and infrastructure resilience.

**Implications:**
Provides objective, scalable screening tool for water resource management, environmental impact assessment, and hydrologic modeling across large domains; transferable framework for national-to-global applications.

**Limitations:**
Validation limited to Ontario; does not incorporate detailed dam operating rules; classification accuracy varies by alteration source type (74% for regulated gauges suggests some misclassification).

**TL;DR:**
Network-based metric maps downstream streamflow alteration from infrastructure across river systems without requiring operational data, validated in Ontario with 86% accuracy for natural streams.
