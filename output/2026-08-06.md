# FESOM2-JAX v1.0 Summary

**Main Contribution:**
A fully differentiable Python reimplementation of the FESOM2 ocean-sea-ice model in JAX that maintains scientific fidelity to the original Fortran code while enabling GPU acceleration and gradient-based optimization. This is the first CMIP-class ocean model natively built in a differentiable framework on unstructured meshes.

**Method:**
- JAX-based re-implementation preserving the unstructured-mesh, cell-vertex finite-volume formulation
- End-to-end differentiability via reverse-mode automatic differentiation through full time loops
- Kernel-by-kernel verification against original Fortran code using finite differences
- Scales from single CPU/GPU to 256 GPUs with identical physics

**Data:**
1958–2019 hindcast simulation at ~1° equivalent resolution with standard climate forcing; validated against observations for temperature, salinity, heat content, and sea ice.

**Climate Relevance:**
Enables rapid prototyping of ocean-sea-ice physics and parameterizations critical for climate projections; supports hybrid physics-machine learning approaches for improved climate model components.

**Implications:**
- Gradient information allows efficient parameter calibration and sensitivity analysis at every mesh vertex
- Facilitates integration of learned components into climate models
- Reduces computational barriers for experimenting with new numerics and physics
- Achieves ~113 simulated years/day on 4 GH200 superchips

**Limitations:**
Computational scaling limited by communication bandwidth rather than arithmetic; largest meshes (~7.4M vertices) require 128 GPUs.

**TL;DR:**
First differentiable global ocean-sea-ice model enabling gradient-based optimization and machine learning integration while maintaining climate model accuracy.

# Research Summary: Memory Compression vs. Physical State for AMOC Prediction

**Main Contribution:**
Compares two neural network strategies for predicting Atlantic Meridional Overturning Circulation (AMOC): augmenting models with explicit physical state (temperature, salinity, density) versus using compact scalar memory. Demonstrates these approaches excel at different prediction horizons and tasks.

**Method:**
- Leave-one-family-out cross-validation across 8 CMIP6 model families (30 trajectories total)
- Direct 20-year forecasts vs. recursive multi-step predictions
- Resolvent analysis to explain learned model stability properties
- Ablation studies isolating memory feedback contributions

**Data:**
30 branch-consistent CMIP6 climate model trajectories under SSP5–8.5 emissions scenario; thermohaline structure variables (salinity, temperature, density) and AMOC index observations.

**Climate Relevance:**
AMOC is a critical component of global heat transport; accurate long-term predictions inform climate impacts on regional weather, sea level, and ocean productivity. Reduced-index monitoring currently discards structural information that may improve forecasting.

**Implications:**
Hybrid approaches combining memory compression (for recursive prediction) with physical augmentation (for near-term state changes) could improve operational AMOC forecasting. Model-dependent transfer limitations suggest ensemble strategies are necessary.

**Limitations:**
Model-dependent performance (negative transfer in MIROC); forcing-dependent compression limits in NorESM suggest findings may not generalize universally across climate models or emissions scenarios.

**TL;DR:**
Memory-based models outperform physics-augmented models for long-horizon AMOC prediction, but physical state better captures near-term ocean changes—requiring task-specific architectural choices.

# Research Summary: Network-Based Streamflow Alteration Mapping

**Main Contribution:**
Introduces the Streamflow Alteration Index (SAI), a network-based screening metric that maps downstream propagation of dam and infrastructure impacts on river flow across entire river networks. Enables spatially continuous assessment of streamflow alteration at both gauged and ungauged locations without requiring detailed dam operation data.

**Method:**
Routes point-based alteration signals (from dams, reservoirs, waterpower facilities) through a hydrologic routing network using paired indices: SAI_I (confirmed sources) and SAI_II (potential sources), both scaled 0–100%. Classification algorithm assigns subbasins to natural, conditional, or altered categories based on cumulative downstream influence.

**Data:**
Ontario Lake and River Routing Product Version 2 (OLRRP v2); inventory of 643 alteration sources from provincial datasets; validation against Reference Hydrometric Basin Network (RHBN) gauges and Water Survey of Canada (WSC) natural/regulated classifications.

**Climate Relevance:**
Supports climate adaptation by enabling rapid assessment of how water infrastructure alters streamflow regimes—critical for aquatic ecosystem health, water availability projections, and hydrologic modeling under changing precipitation patterns.

**Implications:**
Provides objective, scalable screening tool for hydrologic and aquatic applications; applicable at national-to-global scales; reduces computational burden for large-domain assessments by eliminating need for detailed dam operating parameters.

**Limitations:**
Validation limited to Ontario; does not incorporate dam operation rules or seasonal dynamics; classification accuracy among WSC-regulated gauges (74%) suggests potential underestimation of alteration in some contexts.

**TL;DR:**
Network-based metric maps downstream streamflow alteration from water infrastructure across river systems without requiring detailed operational data, validated for Ontario with 86% accuracy on natural gauges.
